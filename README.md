# 🚚 Voyager — Shipping & Delivery Tracking Platform

**Voyager** is a web-based shipping and delivery tracking platform that allows users to monitor package status, view shipment timelines, and access delivery information in real-time.

Built with **React + Vite**, **Tailwind CSS**, **JavaScript**, and powered by **Supabase**, Voyager delivers fast, secure, and scalable tracking experiences for both customers and logistics providers.


## 🌟 Key Features

- 📦 **Real-Time Shipment Tracking**  
  Users can enter tracking IDs and instantly see the delivery status, timeline, and package details.

- 🔔 **Live Status Updates**  
  Dynamic delivery stages such as *Dispatched*, *In Transit*, *Out for Delivery*, and *Delivered* are updated via Supabase.

- 👤 **User Authentication (Optional)**  
  Users can sign in to track multiple packages and view tracking history (Supabase Auth).

- 🧾 **Shipment Data Management**  
  Admins or delivery agents can create and update tracking entries via a secured Supabase database.

- 📱 **Fully Responsive UI**  
  Seamlessly adapts to all devices using Tailwind CSS.



## ⚙️ Tech Stack

| Technology       | Purpose                                  |
|------------------|-------------------------------------------|
| **React + Vite** | Frontend framework and dev environment    |
| **JavaScript**   | Core application logic                    |
| **Tailwind CSS** | Styling and layout                        |
| **Supabase**     | Backend services (Database, Auth, Realtime) |
| **PostgreSQL**   | Managed database behind Supabase          |
